# Maze Delivery Action

MiniPy3DR を使った軽量な 3D 迷路配達ゲームです。

## 実行方法

```powershell
python examples/maze_delivery_action.py
```

## 操作方法

- `WASD` または `矢印キー`: 移動
- `R`: リスタート
- `ESC`: 終了

## ゲーム内容

プレイヤーは迷路の中で荷物を拾い、巡回している警備員を避けながらゴールへ届けます。
制限時間内に配達できればクリアです。

## 基本機能

- キーボード入力によるプレイヤー移動
- 壁との当たり判定
- 荷物の取得
- ゴール判定
- スコア、残り時間、残機の表示
- 勝利、敗北、リスタート処理

## 追加機能

- 警備員が迷路内を巡回する敵 AI
- 警備員に触れると残機が減る
- ボーナストークンを拾うと加点
- 荷物を持っているかを画面上に表示
- 3D キューブで床、壁、プレイヤー、荷物、ゴール、敵を表現

## 工夫した点

- `Maze`, `Player`, `Package`, `Guard`, `BonusToken`, `DeliveryGame` に分けて、役割が分かるクラス設計にしました。
- マップは文字列のリストで管理し、`#` を壁、`S` を開始地点、`P` を荷物、`G` をゴールとして扱います。
- 敵 AI は壁にぶつかると反転する単純な巡回にして、処理が重くならないようにしました。
- 外部画像を使わず、MiniPy3DR の `box` だけで見た目を作ることで、提出時のファイル管理を簡単にしました。
- 関数とメソッドに型ヒントを付け、重要なクラスには docstring を付けました。

## 使用したライブラリ

- `MiniPy3DR`
- `pygame`（MiniPy3DR 内部で使用）
